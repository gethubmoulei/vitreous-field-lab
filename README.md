# 飞蚊症模拟器

[![CI](https://github.com/gethubmoulei/vitreous-field-lab/actions/workflows/ci.yml/badge.svg)](https://github.com/gethubmoulei/vitreous-field-lab/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

一个在浏览器中运行的交互式飞蚊症视觉模拟器。它通过三维柔性丝状物、团状漂浮物、惯性、滞后、阻尼和重力沉降，帮助没有飞蚊症的人直观感受飞蚊症。

> 本项目仅用于视觉现象演示，不构成医学诊断或治疗建议。如出现闪光、飞蚊突然增多、视野遮挡或视力变化，请及时就医。

## 功能

- 丝状和团状漂浮物的实时 Canvas 模拟
- 数量、长度、粗细、蜷曲、透明度与离焦模糊调节
- 灵敏度、响应滞后、玻璃体阻尼与重力沉降调节
- 晴空、阅读、室内和自定义图片背景
- 中文、英文自动识别和手动切换
- 鼠标、触控和降低动态效果偏好支持
- 完全静态导出，无数据库、账号或服务端 API

## 本地开发

要求 Node.js `>=22.13.0`。

```bash
git clone https://github.com/gethubmoulei/vitreous-field-lab.git
cd vitreous-field-lab
npm ci
npm run dev
```

打开 [http://localhost:3000](http://localhost:3000)。

## Docker 部署

```bash
docker compose up -d --build
```

默认访问地址为 [http://localhost:8080](http://localhost:8080)。如需修改端口：

```bash
APP_PORT=8090 docker compose up -d --build
```

## 在 1Panel 中部署

1. 在 NAS 上克隆本仓库。
2. 在 1Panel 的容器编排页面新建编排，并选择仓库中的 `compose.yaml`。
3. 根据需要设置 `APP_PORT`，默认是 `8080`。
4. 启动编排后，在 1Panel 网站页面创建反向代理，目标填写 `http://127.0.0.1:8080`。
5. 为域名启用 HTTPS；公网仅开放反向代理需要的端口，不要暴露 NAS 管理端口。

该镜像在构建阶段生成静态文件，运行阶段只包含 Nginx，不需要 Node.js、数据库或持久化卷。

## English

Vitreous Field Lab is an interactive browser-based eye-floater simulator. It models filament and cloud floaters with configurable inertia, lag, damping, gravity, opacity, blur, and background scenes.

The application is exported as a static site and can be hosted with any web server. Run `npm ci && npm run dev` for local development, or `docker compose up -d --build` for container deployment.

This project is an educational visualization and is not a medical diagnosis. Source code is available under the [MIT License](LICENSE).
